# Brew & Bake ☕🥐

Brew & Bake is a full-stack cafe management and online ordering system built using the MERN stack.

## Project Overview

Brew & Bake is a modern cafe web application where customers can browse coffee, pastries, cakes, and other bakery products, add products to a shopping cart, place orders, and track their orders.

Administrators can manage products, categories, customers, orders, and sales information through an admin dashboard.

## Technology Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Tailwind CSS
- JWT Authentication
